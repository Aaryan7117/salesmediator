SalesMediator (SalesGen)

The Embedded AI Sales Framework
System Requirements Specification · March 2026

1 Project Overview

SalesMediator is an end-to-end, multi-tenant AI Sales Engine framework built to solve the top-of-funnel lead leakage problem in B2B SaaS. Companies lose up to 70% of inbound leads because visitors cannot get immediate, highly contextual answers outside of business hours.

Our solution provides a highly modular, headless-ready architecture that deploys an autonomous AI sales assistant directly onto any client's website via drop-in integration. It replaces static forms and generic chatbots with an intelligent, asynchronous agent that scores buyer intent in real-time and autonomously books meetings and syncs data to CRMs.

2 Features & Functionalities

Feature 1
Dynamic NLP Intent Engine
A proprietary regex-weighted NLP engine calculates the buyer's temperature (Exploring, Comparing, Decision-Ready) on every message, dynamically restricting or empowering the AI's sales tactics.
Feature 2
High-Performance RAG Pipeline
Utilizes a local ChromaDB instance and HuggingFace sentence-transformers mapping directly to the company's knowledge base to guarantee zero-hallucination, perfectly grounded answers.
Feature 3
Zero-Touch CRM Webhooks
The exact millisecond a buyer hits 100% intent, the backend automatically intercepts the flow to trigger Frappe CRM lead injections and Calendly booking modals without any human intervention.
Feature 4
React Native Mobile Dashboard
A native iOS/Android control center (built with Expo & Zustand) allowing sales reps to configure API keys, monitor live AI transcripts, and track lead KPIs remotely.
Feature 5
Multi-Tenant Architecture
Supabase PostgreSQL manages fully segregated organizations. A single unified backend serves distinct, custom-tailored AI agents simultaneously via unique organisation URL slugs.
Feature 6
Web Component Widget
A vanilla HTML/JS and Tailwind frontend that acts as a drop-in component, featuring markdown rendering, voice input support, and real-time typing indicators.

3 Setup & Installation Guide

Prerequisites

Python 3.10+, Node.js 18+, a free Supabase account, and a free Groq API key.

Backend (FastAPI)

cd backend copy .env.example .env # Fill in SUPABASE_URL, SUPABASE_SERVICE_KEY, GROQ_API_KEY pip install -r requirements.txt uvicorn main:app --reload --port 8000 # Backend runs at http://localhost:8000

Mobile App (React Native)

cd mobile npm install npx expo start --clear # Scan the QR code with your iPhone/Android using the Expo Go app

Web Demo (Customer UI)

Open eduflow-demo.html directly in any web browser to experience the end-customer chat interface.

5 Novelty of Your Solution

Most existing solutions are simply wrappers around OpenAI's API that act as disconnected chatbots.

Our approach is entirely novel because it is a closed-loop framework: We engineered a real-time, mathematical Intent Scoring NLP engine that intercepts the semantic layer. By mathematically classifying the user's buying temperature, the system autonomously controls the AI persona via dynamic prompt injection. Furthermore, by building a completely native React Native dashboard, we brought enterprise-grade CRM monitoring directly into the pockets of on-the-go sales reps, bridging the gap between website AI and human workforce mobility.
