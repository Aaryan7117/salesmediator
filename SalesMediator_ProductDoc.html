SalesMediator

AI-Powered B2B Sales Consultant Platform
Product Documentation · Version 1.0

1 Product Overview

SalesMediator is a multi-tenant, AI-powered B2B Sales Consultant platform that deploys a knowledgeable, intent-aware AI sales assistant directly on any company's website.

Problem: B2B companies lose up to 70% of website leads because visitors can't get fast, accurate answers outside business hours. Traditional chatbots are scripted and unaware of the product. Human reps can't be available 24/7.

Solution: SalesMediator gives every business a 24/7 AI rep that knows their product (via a custom knowledge base), scores buyer intent in real-time, adapts its tone to the buyer's stage, and auto-files hot leads into CRM systems the moment they're ready to convert.

3 Intent Scoring Engine

Every buyer message is analysed in real-time using a regex-weighted signal matching engine. The cumulative score (0–100) determines the conversation state and triggers integrations.

4 AI Chat Pipeline (10-Step Engine)

Step 1
Org Resolution
Look up company by URL slug (/chat/acme-corp)
Step 2
Session Management
Create or resume UUID-based lead session
Step 3
Intent Scoring
Score buyer message, update cumulative 0–100 score
Step 4
Persona Detection
Classify buyer type using Groq LLM (first 3 turns)
Step 5
RAG KB Retrieval
Embed query, find top-1 matching KB chunk in ChromaDB
Step 6
LLM Reply Generation
Generate grounded reply using Groq (llama-3.1-70b)
Step 7
Calendly Gate
Show scheduling link only when score threshold is met
Step 8
Integration Triggers
Auto-fire Frappe CRM & GitHub Issues at score ≥ 76
Step 9
Lead Persistence
Save full conversation, signals, persona to Supabase
Step 10
Structured Response
Return reply, intent state, resource card, Calendly flag

9 Setup & Installation

Prerequisites

Python 3.10+ · Node.js 18+ · Supabase account · Groq API key

Backend

cd backend copy .env.example .env # Fill in SUPABASE_URL, SUPABASE_SERVICE_KEY, GROQ_API_KEY pip install -r requirements.txt uvicorn main:app --reload --port 8000 # API docs → http://localhost:8000/docs

Mobile App

cd mobile npm install npx expo start # Scan QR with Expo Go app

Web Demo

Open eduflow-demo.html directly in any browser — no build step required.
